# MaterialCost 物料成本计算

一个基于 **Wails3 + Vue3** 的桌面应用，用于计算化学反应的物料成本、管理物料价格，并支持从 Excel 批量导入物料价格。

## 功能清单

- **物料库管理**：物料（化合物）的新增、编辑、删除、搜索（按编码/名称/CAS/化学式）。
- **价格管理**：每个物料(化合物)的价格新增、编辑、删除、搜索(按供应商、时间、化合物名称、CAS号)。
- **反应成本计算**：单步 / 多步反应，按化学计量比与当量计算单物料成本、总投料成本，按照收率和产物分子量计算产量、根据总投料成本和产量计算产物单位重量成本。
- **方案模板**：反应方案保存 / 载入 / 删除，可复用。
- **Excel 导入**：从 `.xlsx` 批量导入物料与价格，支持模板下载。

## 计算引擎（核心算法）

单位统一为 **kg** 和 **元/kg**：

| 原始单位 | 换算 |
|----------|------|
| 元/g → 元/kg | ×1000 |
| 元/mol → 元/kg | ×1000 ÷ 分子量 |
| g → kg | ÷1000 |

**单步反应**（指定一个底物为 1 eq 基准）：

```
底物有效摩尔数    n₀ = 投料量(kg) × 含量% × 1000 ÷ 分子量

其他物料（当量和投料量至少有一个不为空）：
  当量不为空时：
    摩尔数      = n₀ × 当量
    投料量(kg)  = 理论摩尔 × 分子量 ÷ (含量% × 1000)
    成本            = 实际投料量(kg) × 单价(元/kg) × (1 - 回收率%)
  投料量不为空时：
    摩尔数 = 投料量(kg)*1000 / 分子量
    成本 = 实际投料量(kg) × 单价(元/kg) × (1 - 回收率%)
本步总成本 = 所有物料成本之和

产物(重量收率、摩尔收率、产量三者至少有一个不为空)：
  单位成本(元/kg) = 本步总成本 ÷ 产量(kg)
  产量不为空：        
    重量收率 = 产量/底物投料量
    摩尔收率 = （产量/产物分子量）/(底物投料量/底物分子量)
  重量收率不为空：
    产量 = 投料量 * 重量收率
    摩尔收率 = （产量/产物分子量）/(底物投料量/底物分子量)
  摩尔收率不为空：
    产量= （底物投料量/底物分子量）* 摩尔收率 * 产物分子量
    重量收率 = 产量/底物投料量


```
**参数校验(警告且阻塞)**：

1. 当量、投料量至少有一个不为空
2. 摩尔产率、重量产率、实际产量至少有一个不为空

**参数自动计算**：

1. 当量、投料量有一个为空时，根据已有的计算为空的
2. 摩尔产率、重量产率、实际产量有空值时，根据已有的计算为空的

**参数互校验（警告不阻塞）**：

1. 实际投料量 ↔ 当量反推理论投料量，偏差 > 1% → 警告
2. 摩尔产率 ↔ 重量产率不一致（考虑含量）→ 警告
3. 实际产量 ↔ 填写的产率不一致 → 警告
4. 价格为 元/mol 但缺少分子量 → 警告

**多步反应**：按步骤顺序计算，中间产物自动传递——上一步产物的「单位成本 + 实际产量 + 分子量」作为下一步继承原料的「单价  + 分子量」，下一步分投料量是可修改的。

**Excel 导入规则**：

- 模板列：`物料名称 | CAS号 | 化学式 | 分子量 | 价格 | 价格单位 | 单供应商 | 日期 | 规格 | 含量 | 备注`
- 表头按别名容错匹配；「CAS」必填。
- 按 CAS 导入物料，已有CAS的更新物料名称 | CAS号 | 化学式 | 分子量 等字段
- 其他存入价格记录字段，价格 | 价格单位 | 单供应商 | 日期 | 规格 | 含量 | 备注
- 日期支持字符串（`2026-08-25`）与 Excel 序列号。

## 前端页面

- **物料库**：物料列表（编码/名称/含量/回收率/当前价格/供应商/日期），搜索、新增/编辑弹窗、价格历史抽屉、Excel 导入与模板下载。
- **反应计算**：多步骤动态编辑，原料表格（分子量/单价/当量/含量/回收率/投料量/底物标记/中间产物继承），产物表格（计量数/产率/实际产量），实时显示成本与产率，黄标警告，方案保存/载入。
- 前端设计 尽量使用原有的组件
- 标记为底物需要有标记
- 继承前一步的产物为底物时，保留名称、分子量、但是投料量可自己编辑
- 继承前一步的产物时，本行不能再从物料库选择物料

## 关键设计决策

1. **纯 Go 计算引擎**（`internal/engine`）：计算与校验逻辑独立成纯函数，便于单元测试。
2. **价格同步**：若一个化合物有多个价格记录，在计算成本时自动使用日期最新的记录，单给出下拉框以供选择，下拉框需要显示价格时间和规格等信息
3. 数据补全，投料量等数据不全时根据已有数据计算未知数据
4. **校验「警告不阻塞」**：参数不自洽时前端黄标提示，但不阻止保存/计算，允许手工覆盖。
5. **SQLite 免 CGO**：使用 `modernc.org/sqlite` 纯 Go 驱动，跨平台交叉编译无需 C 工具链。
6. 尽量使用组件库的组件，不手搓组件
