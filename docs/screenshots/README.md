# 截图目录

把应用截图放到本目录，然后在**根目录 README.md 的徽章行上方**插入：

```html
<p align="center">
  <img src="docs/screenshots/materials.png" width="32%" alt="物料库" />
  <img src="docs/screenshots/reaction.png"  width="32%" alt="反应计算" />
  <img src="docs/screenshots/schemes.png"   width="32%" alt="方案管理" />
</p>
```

| 文件名 | 内容 |
|--------|------|
| `materials.png` | 物料库页面（列表 + 搜索 + 价格历史抽屉） |
| `reaction.png` | 反应计算页面（多步编辑 + 成本汇总） |
| `schemes.png` | 方案管理页面 |

建议宽度 1280px 左右，PNG 格式。
